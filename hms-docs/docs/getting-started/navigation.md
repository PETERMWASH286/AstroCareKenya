# Navigation & Productivity ⚡  
Master AstroCare like a power user

This page is your **daily productivity playbook** — keyboard shortcuts, module flow, and UX tips to perform tasks faster and safer.

## Quick access (the 10-second tour)
- **Dashboard:** High-level hospital KPIs, recent activity, and shortcuts.
- **Global Search (press `/`)**  
  Search patients, invoices, lab orders, and radiology studies from a single box.
- **Create + (Quick Action)**  
  Globally available `+` button to add patient, appointment, lab order, invoice, or prescription.
- **Notifications (bell)**  
  Real-time alerts for critical lab results, payment receipts, and approvals.

---

## Main layout & consistent patterns
1. **Top Navigation (Global)**
   - Brand / Organization selector (if super admin or multi-hospital)
   - Global search
   - Notifications
   - User menu (Profile, Settings, Help, Sign out)

2. **Left Sidebar (Module Nav)**
   - Collapsible, persistent across pages
   - Shortcuts to: Dashboard, Patients, Appointments, Billing, Lab, Radiology, Pharmacy, HR, Reports, Admin

3. **Content Area**
   - Page content, contextual actions, and inline help
   - Always look for the **Help (?)** pill on each page to open quick tips

4. **Contextual Action Bar**
   - Actions that apply to the current record: Save, Print, Create Order, Discharge, Transfer

## Workflows — examples & best practices

### Patient visit (fastest path)
1. ` / ` → search patient by name/ID  
2. In patient view → `+ Create Visit` → add reason, clinician, and queue  
3. From visit: `Order Lab` → choose panel → `Send to Lab` (results will attach when ready)

### Admit to Inpatient Ward
1. Open patient → `Admit` → choose ward and bed  
2. Create initial orders (baseline labs, imaging) via the `Orders` quick-action  
3. Use `Care Plan` tab to add nursing notes and medications

### Billing with M-Pesa (Quick flow)
1. Create invoice → choose payment method **M-Pesa**  
2. Click `Send Payment Request` → patient receives Mpesa STK push  
3. Payment confirmed → invoice marked paid, receipt generated automatically

## Shortcuts & keyboard power
- `/` → Focus global search  
- `g d` → Go to Dashboard  
- `g p` → Go to Patients  
- `n p` → New Patient  
- `n a` → New Appointment  
- `?` → Open keyboard shortcut help modal

> Tip: The shortcut modal is accessible from anywhere and can be customized for role-based shortcuts.

---

## Productivity tips for power users
- **Pinned filters:** Save commonly used filters in lists (e.g., Today's Appointments, Pending Lab Results).
- **Saved dashboards:** Create and share custom dashboard views for finance, clinical leads, and admins.
- **Bulk actions:** Multi-select in lists to export, bill, or archive records.
- **Audit mode:** Toggle audit trail to review changes before pushing major updates.

## Troubleshooting navigation issues
- If a module is missing: check **Role & Privileges** in Admin.  
- If pages look unstyled: verify that your browser cache is cleared or the CDN/static assets deployed properly.
