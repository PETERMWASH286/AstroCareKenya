    Security & Compliance — AstroCare¶

    AstroCare is built with security and privacy at its core, ensuring that hospital operations, patient records, and sensitive financial data remain safe, compliant, and fully auditable. Our system integrates multiple layers of protection, combining modern encryption, authentication, and regulatory-compliant workflows.

    🔐 User Account Security¶

    1. Password Encryption
    2. All user passwords are stored using strong hashing algorithms (e.g., bcrypt/Argon2).

    3. Enforces minimum password strength: length, complexity, and expiration policies.

    4. Two-Factor Authentication (2FA)

    5. Users can enable 2FA via SMS OTP or Email OTP.
    6. Protects against account compromise, even if passwords are leaked.

    7. Recommended for super admins, finance, HR, and doctors handling sensitive data.

    8. Session & Device Management

    9. Monitor active sessions per user.
    10. Option to terminate sessions remotely.

    11. Detects suspicious login attempts and geo-anomalies.

    12. Role-Based Access Control (RBAC)

    13. Fine-grained control: Doctor, Nurse, Lab Tech, Pharmacist, Accountant, HR, Admin, Super Admin.
    14. Each role has strictly limited permissions to prevent unauthorized access.

    🏥 Patient Data Security¶

    1. Health Act 2017 & Data Protection Act 2019 Compliance
    2. All patient data is encrypted at rest (AES-256) and in transit (TLS 1.2+).
    3. Automatic audit trails record every access or modification.

    4. Only authorized personnel can view sensitive data.

    5. Digital Health Superhighway Integration

    6. When accessing patient data across facilities, patient consent is required.
    7. OTP sent to the patient via email or SMS before cross-hospital access is granted.

    8. Full traceability of access requests and patient approvals.

    9. Data Minimization & Anonymization

    10. Sensitive fields are masked when not required (e.g., billing-only reports).
    11. De-identified data is used for analytics and reporting to reduce privacy risk.

    🌐 System Security & Infrastructure¶

    1. Network Security
    2. Configured with firewalls, VPNs, and intrusion detection/prevention systems (IDS/IPS).
    3. Enforces HTTPS across all endpoints.

    4. DDoS protection and rate limiting to prevent attacks.

    5. Database & Storage Security

    6. Database access is encrypted and restricted to authorized services.
    7. Backup data is encrypted and stored securely.

    8. Automatic replication for disaster recovery.

    9. Application Security

    10. Input validation and sanitization prevent SQL injection, XSS, CSRF attacks.
    11. Security headers (CSP, HSTS) applied to all pages.

    12. Regular security audits and vulnerability scans.

    13. Logging & Monitoring

    14. Centralized logging of all system events.
    15. Real-time monitoring for anomalies and unauthorized access.
    16. Alerts sent to admins and security officers for suspicious activity.

    🛡 Security for Integrations¶

    • API Security
    • All internal and external APIs require authentication tokens.
    • Rate-limited to prevent abuse.

    • Endpoints handling patient data require explicit consent checks.

    • Payment & Financial Data

    • M-Pesa, PayBill, and other payment flows are encrypted.
    • PCI-DSS compliance for payment processing.

    📌 Best Practices for Users¶

    • Use strong, unique passwords and enable 2FA.
    • Regularly review access logs for your account.
    • Do not share credentials, even with colleagues.
    • Report any suspicious activity immediately.
