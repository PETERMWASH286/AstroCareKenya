    Welcome to the AstroCare FAQ! This page covers common questions from hospitals, staff, and patients. We’ve structured it for easy scanning and modern readability, so you can quickly find answers.

    General Questions¶

    Q1: What is AstroCare?
    AstroCare is a web-based Hospital Management System (HMS) designed to manage multiple hospitals, patients, billing, lab services, HR, and more, from a single modern dashboard. Learn more: AstroCare Overview

    Q2: How can my hospital access AstroCare?
    Hospitals can access AstroCare via a secure web URL (SaaS) or private cloud/on-prem deployment.
    Example: https://<hospital-shortname>.astrocarekenya.com
    Learn more: Getting Started

    Q3: Is training required for staff?
    Yes, AstroCare provides training guides, workshops, and video tutorials to ensure smooth onboarding.

    Patient Management¶

    Q1: How do I register a new patient?
    Navigate to Patients → Add Patient. Fill in demographic details, medical history, and insurance information.

    Q2: Can I search patients across hospitals?
    Yes! AstroCare connects with the Digital Health Superhighway (Kenya) to search patient records securely across participating hospitals.

    Q3: How do I update patient information?
    Click on the patient profile → Edit → Save. Changes are logged automatically for audit purposes.

    Appointments¶

    Q1: How do I book an appointment?
    After patient registration, go to Appointments → New Appointment.
    - Select visit type: General Consultation, Dental Clinic, Optician Clinic, Special Clinics, Walk-in (Lab/Radiology/Pharmacy).
    - Assign a doctor and preferred date/time.

    Q2: How do doctors view their schedules?
    Doctors access My Schedule in their dashboard. Bookings appear in real-time, with notifications for new appointments.

    Billing & Payments¶

    Q1: How can patients pay?
    Patients can pay via:
    - M-Pesa STK Push / PayBill (pre-service payment is required for Lab, Pharmacy, and Consultations).
    - Cash at billing counters.
    - Insurance (must be configured in Finance module).

    Q2: Are transactions logged?
    Yes, all transactions, including payments, refunds, and insurance claims, are securely logged and auditable.

    Learn more: Billing & Payments

    Laboratory & Radiology¶

    Q1: How do lab sample collections work?
    Samples are registered in the system, linked to patient appointments. Lab staff can approve, reject, or request re-sampling if needed.

    Q2: Can I track lab results?
    Yes. Results are entered, reviewed, and approved, with parameters, reference ranges, and quality control checks.
    Integration with LOINC FHIR API ensures standardization.

    Learn more: Lab Module | Radiology Module

    Human Resources (HR)¶

    Q1: How is attendance tracked?
    HR can manage staff clock-ins, duty rosters, leaves, and absences directly in AstroCare.

    Q2: Does AstroCare support payroll?
    Yes, payroll is automated based on attendance, roles, and salary structure. Reports are exportable.

    Learn more: HR Module

    Administration & Super Admin¶

    Q1: What can a hospital admin do?
    - Manage all department reports and audit logs.
    - Manage hospital profiles, facilities, and board communications.
    - Receive notifications for approvals, backups, and resource center updates.

    Q2: What can a super admin do?
    - Manage multiple hospitals from a single dashboard.
    - Add new hospitals, view consolidated reports, and configure global settings.

    Learn more: Admin Module

    Security & Compliance¶

    Q1: How is patient data protected?
    - Health Act 2017 and Data Protection Act 2019 compliance.
    - Role-based access control, encryption in transit and at rest, audit trails, and OTP-based consent for Digital Health Superhighway access.

    Q2: How are user accounts secured?
    - Encrypted passwords, Two-Factor Authentication (2FA via email/SMS OTP), and session management.

    Learn more: Security Module

    Integrations¶

    Q1: What external systems are integrated?
    - Digital Health Superhighway (patient info, eClaims, worker registry).
    - LOINC FHIR API for lab tests.
    - WHO ICD-11 API for diagnostics.
    - Africa’s Talking Bulk SMS and email notifications.

    Learn more: Integrations

    Support & Troubleshooting¶

    Q1: How do I get help?
    - Contact our support team at: support@astrocare.com
    - Access guides, tutorials, and community discussions online.

    Q2: What if I encounter errors?
    - Check Troubleshooting page: Support Troubleshooting
    - Common issues include browser compatibility, network access, and incorrect user permissions.

    💡 Pro Tips¶

    • Use the search bar in AstroCare to quickly find modules, patients, or reports.
    • Enable notifications to never miss critical updates.
    • Regularly backup your hospital data from Admin → System Settings.
    • Encourage staff to update credentials and enable 2FA for security.

    AstroCare’s FAQ is continuously updated to ensure you have the latest answers for smooth hospital operations.
